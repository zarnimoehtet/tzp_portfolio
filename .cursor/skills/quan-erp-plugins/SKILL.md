# Quan ERP External Plugins Skills

This skill category contains references and development patterns for external Quan ERP plugins.

## Instructions for AI Agents
- **Watch Scope**: Always monitor the subdirectories within `.agents/skills/quan-erp-plugins/` to discover specialized skills for specific plugins.
- **Usage**: When working on a specific plugin (e.g., `payment-method`), refer to its local `SKILL.md` for specific implementation patterns and API references.

- [Barcode Scanner Plugin](./barcode-scanner/SKILL.md): programmatic barcode and QR code scanning logic.
- [Cron Scheduler Plugin](./cron-schedular/SKILL.md): Dynamic cron job management and execution.
- [Base Plugin](./base/SKILL.md): Core ERP infrastructure APIs (Users, Branches, Partners, Files, etc.).
